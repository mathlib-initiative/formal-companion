\section*{Introduction}
This is an informal account, in our own words, of the definitions and results
on which the theorem {{ theorem_tex }} of the Lean library {{ library_name_tex }}~\cite{library}
depends, in the order in which they build on one another.  It contains no
proofs: the proofs are the Lean code.  Each numbered statement, and each
lettered part of one, corresponds to the Lean declaration that states it, and
is linked to that declaration when this text is read beside the Lean source.
The text is released under {{ license_tex }}.
